## Conformité constatée

- `tokens.css` du code identique à la source ; aucune valeur de couleur codée en dur dans les CSS de la scène. Les seules valeurs hors échelle (6 px, 10 px) sont celles de la maquette, commentées.
- Barre de vue : `.glass` pilule, padding `--space-2` (6 px sous 420 px de conteneur), gap `--space-2`, centrée à `--float-inset` du bas. Boutons 36 px, icône 20 px + libellé 14/500, survol `--color-surface-2`, pressé = fond `accent-subtle` + contour 2 px + coche à la place de l'icône + poids 600, focus = anneau standard avec contour conservé. Conforme à la maquette (captures claire et sombre).
- Info-bulle inversée (`--color-text` / `--color-surface`), `--radius-sm`, 6/10 px, alignement gauche/droite sur les boutons d'extrémité, `aria-describedby` via React Aria, Échap.
- Astuce : verre, `--radius-xl`, 12/16 px, icône `--color-info`, « Got it » Button sm, X ghost icône sm avec `aria-label`, repli sous 560 px (capture 683 px correcte). Ordre DOM barre puis astuce, `column-reverse` pour l'affichage (choix justifié par UX-3).
- Chargement : fond `--scene-floor`, texte 16/500, piste 8 px `--color-border` + liseré `--color-border-strong`, remplissage `--color-accent`, nom via `aria-labelledby`.
- Erreur : carte opaque `--color-surface`, `--radius-xl`, `--shadow-3`, max 520 px, badge 48 px, titre `--text-xl`/600 `tabindex=-1` focalisé, `role="alert"`, bouton primaire. Textes identiques à la maquette hors « this page ».
- Scène : anneau de focus décalé de -3 px (`Viewport.tsx`), curseurs grab / grabbing / move dans `viewRig.ts`.
- Tokens et mode sombre : captures cohérentes, contrastes inchangés par rapport à la maquette.
