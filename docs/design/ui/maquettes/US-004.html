US-004 / Sprint 1 / High-fidelity mockup

3D scene and view bar

Studio scene filling the frame, floating glass view bar (Reset view, Top, Front), dismissible tip, loading and "3D unavailable" states, light and dark. The scene image below is a placeholder drawing: the real render comes from Three.js (assets/catalog/scene/studio.json). Everything else (bar, tip, messages, tooltips, focus) is the final design. Back to the design system.

Glass fallback = opaque surface (no backdrop-filter / reduced transparency). Reduced motion = camera, tip and bar animations become instant, progress bar is static. Your OS settings are also honoured.

1. Scene ready (nominal, tip visible)

Try it: click Top / Front / Reset view, hover or Tab to a button for its tooltip (400 ms, Esc closes), click "Got it" or X (focus moves to Reset view), drag the scene (the pressed button clears), focus the scene (Tab) and press 0, 1 or 2. Fade over 480 ms (--duration-camera, --ease-in-out) stands in for the real camera move.

2. Tip hidden

The bar does not move. The tip stays hidden for good (preference stored in the browser) until Help (US-025) can reopen it.

3. Loading

Plain studio background (--scene-floor), no bar, same reserved size as the canvas (no layout shift).

4. 3D unavailable

Opaque message (no glass), role="alert", focus goes to the title, no bar and no tip. The "Try again" button re-runs initialisation. In this demo it shows the loading state then returns here.

7. For the developer

Components to reuse (design-system.md sections 7, 8, 9, 14)

  • SceneToolbar (RAC Toolbar, role="toolbar" aria-label="View"): .glass pill, padding --space-2 (6 px under 420 px), gap --space-2, bottom-centre at --float-inset from the edge. Buttons: --control-md (36 px) high, pill, icon 20 px + visible label 14 px/500 (no aria-label needed: the text is the name). Reset view has no aria-pressed; Top and Front are toggle buttons (aria-pressed), at most one pressed, cleared by any manual view change and by Reset view.
  • Pressed = --color-accent-subtle fill (opaque) + --color-accent-subtle-text + 2 px --color-accent contour + check icon replacing the view icon (same slot, so no layout shift) + weight 600. With focus: keep the contour, add the standard focus ring.
  • Tooltip: inverted (--color-text background, --color-surface text), --text-sm, --radius-sm, delay 400 ms on hover and on focus, Esc closes without moving focus, linked with aria-describedby. Align left on the first button, right on the last, to stay inside the scene at 375 px.
  • Tip: .glass, --radius-xl, padding --space-3/--space-4, 14 px, info icon --color-info; "Got it" = secondary Button sm, X = ghost icon button sm (32 px, aria-label="Hide tip"). Below 560 px width the buttons wrap under the text. Max width 720 px, centred above the bar, gap --space-2.
  • Loading: background --scene-floor, text 16/500, role="progressbar" 8 px high (track --color-border + 1 px --color-border-strong inset, fill --color-accent), message in a polite aria-live region. Static under reduced motion.
  • Error panel (WebGL / context lost): opaque card (--color-surface, --radius-xl, --shadow-3, max 520 px), 48 px badge --color-error-bg + --color-error triangle icon, title --text-xl/600 with tabindex="-1" to receive focus, body 16 px --color-text, primary Button "Try again" (.btn.primary, --control-md).
  • Scene: cursor grab / grabbing (rotation) / move (right-drag); focus ring on the viewport inset (outline-offset: -3px) so it is not clipped; reserve the canvas size before it loads.

Tokens used

  • Glass: --glass-tint, --glass-border, --glass-shadow, --glass-filter via the .glass class (fallbacks included, never below 86 %).
  • Colour: --color-text, --color-surface, --color-surface-2 (hover), --color-accent*, --color-info, --color-error, --color-error-bg, --color-border, --color-border-strong, --color-focus; scene: --scene-bg-top/bottom, --scene-floor. 3D colours of the studio itself come from studio.json.
  • Shape and size: --radius-pill (bar, buttons), --radius-xl (tip, error card), --radius-sm (tooltip), --control-md, --control-sm, --control-lg, --space-2/3/4/6/8, --float-inset, --focus-width, --focus-offset.
  • Motion: --duration-fast (hover/press), --duration-slow + --ease-spring (bar and tip entrance), --duration-camera + --ease-in-out (view change; 0 ms under reduced motion, which also drops the inertia), --press-scale.
  • No new token was needed.
