3D scene and view bar

Behaviour is unchanged from Sprint 1; only the look changes: the view bar is a floating pill of thin material with pill buttons, the tip is a regular material strip, errors are opaque cards, the focus ring is the accent halo. The scene drawing is a placeholder for the Three.js render. Frames here are the scene alone; in the app they sit inside the shell (US-005).

7. For the developer

  • View bar (Toolbar, aria-label="View"): material-thin float, pill, padding 4 px (3 px under 420 px), buttons 36 px pill, 2 px gap, icon 18 px + label 15/500. Reset view has no state; Top and Front are toggle buttons (aria-pressed). Pressed = --color-accent-subtle fill + --color-accent-subtle-text + weight 600 + check icon in the icon slot (no layout shift). The former 2 px accent contour is gone (the check is the non-colour cue). Hover = --color-fill-hover. Bottom centre of the free zone, --space-5 above the edge.
  • Tooltip: inverted (--color-text background, --color-surface text), Footnote 14, --radius-sm, above the button, 400 ms on hover, immediate on keyboard focus, Esc closes without moving focus, aria-describedby.
  • Tip: material-regular float, --radius-xl, Subheadline 14, info icon --color-info (3.5:1 on the worst background, 3 required for an icon), "Got it" = default Button sm, X = ghost icon button 32 px (aria-label="Hide tip"). Under 560 px the buttons wrap below the text. Max 720 px, centred above the bar, gap 8 px.
  • Loading: --scene-floor background, Headline text, role="progressbar" 6 px high (track --color-fill + 1 px --color-border-strong inset, fill --color-accent-solid), polite live region. Static under reduced motion.
  • Error card (WebGL / context lost / failed, see US-005): opaque (--color-surface, --radius-xl, --shadow-3, max 520 px), 48 px --color-error-bg badge with the alert icon, Title 2 (tabindex="-1", focus target), body 16, primary Button.
  • Scene: cursor grab / grabbing / move; focus ring inset (outline-offset: -4px); reserve the canvas size before it loads. Motion: bar and tip enter with --ease-spring over --duration-spring; view change --duration-camera / --ease-in-out (0 under reduced motion).
