US-005 / Sprint 2 / high-fidelity mockup

Studio shell

A native-style app window: unified toolbar, source-list sidebar, grouped-form inspector, and the 3D scene as a full-window canvas underneath translucent materials. Same structure as the UX wireframes (top bar, left panel, scene, right panel); only appearance and patterns change. The scene drawing is a placeholder for the Three.js render. Frames are real 1366 x 768 / 1180 x 820 / 820 x 1000 / 375 px layouts, scaled to fit your window; the layout follows the width of the app frame (container queries), not of this page.

Scope reminder: no Undo/Redo, File, Help or "Saved" (decision of the PO: hidden until the function exists). The verdict only has its empty state "Nothing to check yet". Panel toggles live in the toolbar and keep their place whether the panel is open or not.

7. For the developer

Structure and components

  • Layout: a grid auto 1fr on a container (container: app / inline-size); toolbar in row 1; both aside and main are positioned in row 2 / the whole frame. DOM order = tab order: skip links, header, left aside, main, right aside. The scene (main) fills the whole frame (z 1) under the panes (z 3) and the toolbar (z 4); skip links z 60. The page never scrolls; panes scroll inside. Layout reacts to the container width. Threshold 1024 px (docked above, overlays below), 640 px (toolbar wraps), 560 px (inspector sheet).
  • Free zone (camera framing, dock): between the panes when docked, i.e. 1366 - 248 - 312 = 806 px at 1366 px (it was 758 px with the floating panels of v0.3); in inset chrome, 1180 - 2 x 12 - 248 - 312 - 2 x 12 = 560 px. Below 1024 px: the whole width. The dock and the scene art are centred in it and do not move when a panel collapses (only recomputed on load / Reset view / Top / Front / desk change). Expose it as CSS variables --dl / --dr (or measure the panes).
  • Toolbar (Toolbar, material-regular, hairline --color-separator, min height --topbar-h 52): left toggle (tool button 40 px, icons panel-left-close / -open, constant name "Desk and objects panel", aria-expanded, aria-controls, tooltip "Hide panel" / "Show panel"), wordmark h1 (headline 700 + 10 px accent dot, no logo), a 1 px separator, document name (callout 500, truncated with title), verdict (status pill), right toggle. Undo/Redo, File, Help and "Saved" are not rendered.
  • Verdict: role="status", 36 px pill, --color-surface-2 background, text 15/600 --color-text, circle-dashed icon in --color-text-muted. States from US-017: success-bg / warning-bg / error-bg with their icon + word. Always visible, wraps to the second row under 640 px.
  • Sidebar (material-regular, 248 px, hairline on the inner edge): segmented control (tablist, spring thumb) Desk / Objects, then the tab panel. Section title = Headline 16/600, help = Subheadline 14 muted. Empty states: 44 px badge + Headline + Subheadline in a white radius-lg group. Desk content: see US-006.
  • Inspector (material-regular, 312 px): section + h2 "Properties", "Alerts"; empty state in a grouped card. Later content uses grouped rows (label left, value right, 44 px min).
  • Panels: open/close = translate + fade with --ease-spring-soft over --duration-spring; visibility: hidden after the transition (out of the tab order and the accessibility tree), focus stays on the toggle. Tiers: docked (flush, hairline) / inset (iPad landscape: --float-inset margin, radius-xl, --glass-shadow) / overlay (< 1024) / popover (inspector, 560-1023) / bottom sheet (inspector, < 560, radius-xl top corners, 36 x 5 grabber). Overlay width min(--drawer-max-w, 100% - 64px); one open at a time.
  • Scene states: loading (floor colour, 16/600 text, 6 px progress bar, indeterminate), unsupported / failed / context lost: opaque card (--color-surface, radius-xl, --shadow-3), 48 px error badge, Title 2, body 16, stacked buttons ("Try again" primary, "Reload page" default from the 2nd failure only). role="alert", focus on the title (tabindex="-1", no ring).
  • View bar and tip restyled (US-004 behaviour unchanged): bar = material-thin float pill (primary-text labels only, thin material), 4 px padding, 36 px pill buttons with 2 px gap; pressed = accent-subtle fill + check replacing the icon + 600 (no 2 px contour any more; the check is the non-colour cue). Tip = material-regular float, radius-xl, "Got it" default small button, X ghost icon button 32 px.
  • Skip links: opaque pills (surface, 40 px, --shadow-3), visible on focus only, above everything.
  • Reduce transparency: .no-glass / prefers-reduced-transparency / no backdrop-filter give opaque --material-solid (the same gray as the window) and nothing else changes.
  • Reduced motion: all --duration-* become 0; the loading bar is static and centred.

Deviations from the UX document (to validate)

  • The panel toggles moved from inside each panel to the toolbar (as in a native window): the right toggle now comes right after the left one in Tab order, before the panes and the scene. UX-5 says it comes last. Option: keep the DOM order of UX-5 by placing the right toggle after main and positioning it in the toolbar with the grid.
  • Undo/Redo are not rendered (PO decision) so the toolbar has no empty slot.
