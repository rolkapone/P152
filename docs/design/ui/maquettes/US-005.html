US-005 / Sprint 2 / High-fidelity mockup

Studio shell

Top bar with the empty verdict, two foldable glass panels, the scene with a placeholder studio image, drawers under 1024 px, scene states (loading, 3D unavailable, failed with "Reload page" from the 2nd failure, stopped), skip links, light and dark. The desk drawing is a placeholder: the real render comes from Three.js. Panel content for the Desk tab is detailed in US-006. Back to the design system.

Glass fallback = opaque surfaces, no blur (.no-glass). Reduced motion = panel fold, camera and bars instant, loading bar static. The page theme follows your system; each frame forces its own theme. Frames are scaled to fit the window; their layout is computed at the real size.

1. Studio at 1366 x 768, light Pending PO validation: UX defaults applied

Try it: fold the panels with the buttons in their corner (the dock and the framing do not move), switch tabs (arrow keys too), pick a desk, press Tab from the top (skip links appear), hover or Tab to a panel button for its tooltip (400 ms on hover, immediate on keyboard focus, Esc closes). Defaults applied while waiting for the PO: Undo / Redo not rendered until US-019, verdict "Nothing to check yet" (not "It fits"), Objects tab shown with an empty state.

2. Same screen, dark

Dark studio (--scene-*), glass tint 86 % dark. Same structure, same contrast rules.

3. Folded panels (wide screens)

A folded panel keeps only its 40 px button (glass chip, same corner). The choice is remembered on large screens. Folding never moves the camera or the view bar: they re-centre only at the next load, "Reset view", "Top", "Front" or a desk change.

4. Small screens: drawers

Under 1024 px (this includes 1366 x 768 at 200 % zoom = 683 x 384 CSS px) panels are drawers, closed at load, one open at a time. A drawer covers the scene but never the top bar, so the verdict stays visible. Esc closes the drawer and puts the focus back on its button. At 320 px (400 % zoom) the verdict drops to a second line and the view bar wraps.

5. Scene states inside the shell

Top bar, verdict and panels stay usable in every state. Cards are opaque, role="alert", focus goes to the title on each new attempt; no view bar, no tip. In this demo "Try again" shows the loading state then fails again (the 2nd failure adds "Reload page"). "Reload page" is never offered for "3D unavailable" or "stopped".

6. Skip links and tab order

Skip links are the first two Tab stops: invisible until focused, then opaque pills above the top bar with the standard focus ring (never hidden by a panel). Left: first skip link focused. "Skip to alerts" opens the right panel if folded and moves the focus to the "Alerts" title.

  1. Skip to 3D view, then Skip to alerts
  2. Left panel button, then the selected tab (Desk or Objects), then the tab content (the desk list is one tab stop)
  3. 3D view (viewport), Reset view, Top, Front, Got it, Hide tip
  4. Right panel button, then its content (nothing focusable in US-005)
  5. Not reached: the setup name (text), the verdict (status text), disabled controls

7. Alternative while the PO decides Pending PO validation

Only if the PO answers "show Undo / Redo now": two disabled icon buttons after the setup name (--control-md, icons undo-2 / redo-2, disabled colour --color-text-disabled, not focusable). The recommended default is to leave them out.

8. Before the app starts (no JavaScript)

index.html paints the theme background (no white flash in dark) and a <noscript> message. This text is static English, outside i18n.

Turn on JavaScript to use this app.

9. For the developer

Structure and components (design-system.md sections 9, 15)

  • Shell: one container with container-type: inline-size (or the equivalent @media on the viewport width: the breakpoint is 1024 px for "drawer mode"). CSS grid, padding and gap --float-inset, rows auto 1fr. DOM order = Tab order: skip links, header (top bar), aside left, main, aside right. Visually the main (canvas) spans the whole frame under the others (z-index: main 1, panels 2, top bar 3, skip links --z-skip). The page never scrolls; panels scroll inside (.p-body, overscroll-behavior: contain).
  • Top bar: .glass, --radius-xl, min height --topbar-h, padding --space-2/--space-5, flex-wrap: wrap. Wordmark = h1 "Deskfit" from i18n (app.name), 18/600, small accent square (CSS, no asset). Setup name: 16/500, one line with ellipsis and title, flex: 1 1 96px; min-width: 0, left hairline --color-border. Verdict: role="status", margin-left: auto (stays right and drops to a 2nd line when space is short), height --toggle-size, pill, fill --color-surface-2 opaque, 1 px --color-border-strong, 18/600, icon circle-dashed in --color-text-muted + text "Nothing to check yet". Never icon only. Future states (US-017) use *-bg fills as in the design system.
  • Panels (aside, .glass, --radius-xl): width --panel-left-w / --panel-right-w, full height of the grid row. The toggle is the first child (RAC Button + Tooltip), --toggle-size, --radius-lg, positioned at --space-2 from the panel's outer top corner (left: top-left; right: top-right), constant accessible name ("Desk and objects panel" / "Properties and alerts panel"), aria-expanded, aria-controls on the scrolling body, icon panel-left-close / panel-left-open (right: panel-right-close / -open), tooltip "Hide panel" / "Show panel". Folded = same element shrunk to a glass chip of --toggle-size + --space-4 (56 px) square; the head and body get visibility: hidden after the 320 ms fade (or inert) so they leave the Tab order and the accessibility tree. Transition: width/height + opacity + 8 px translation, --duration-slow, --ease-out; 0 ms under reduced motion (tokens do it). Focus stays on the toggle.
  • Drawers (container < 1024 px): same component, closed by default, never stored open. Open width = min(var(--drawer-max-w), 100% - 64px) (64 = the other panel's 56 px chip + 8 px, so its button stays visible and reachable). Opening one closes the other. Not modal: no focus trap, no scrim. Esc with the focus inside closes it and returns the focus to its toggle. The top bar is never covered (the drawer lives in the grid's second row).
  • Left panel head: .p-head (56 px, left padding 56 px to leave room for the toggle) holds the tabs: role="tablist" segmented control (--radius-pill, --color-surface-2 track, 3 px padding), tabs --control-sm high, 16/500 muted; selected = --color-accent-subtle fill + --color-accent-subtle-text + 600 + 2 px --color-accent contour (never colour alone). Arrow keys switch (automatic activation), Tab goes to the panel content. RAC Tabs. Right panel head is an empty 48 px band (the toggle sits in its top-right corner).
  • Panel sections: .p-body padding --panel-pad; titles are h2 styled as the overline (14/600, uppercase, --color-text-muted); empty-state title 16/600; explanation 14 --color-text-muted; sections separated by a 1 px --color-border line. "Alerts" title has tabindex="-1" (target of "Skip to alerts"; no focus ring on it, it is not a control).
  • Viewport / dock: viewport = role="group" tabindex="0" (US-004), focus ring inset by 3 px. The dock (view bar + tip) is positioned in the free zone: left: panel-left-w + 2 * inset, right: panel-right-w + 2 * inset when the panel was open at load (12 px otherwise or in drawer mode), computed at load only (no movement when a panel folds). Under 440 px (container) the bar uses 6 px padding; under 340 px it wraps and uses --radius-xl. The tip wraps under 700 px.
  • Scene states: loading = --scene-floor background covering the viewport (not the panels), card or text centred in the free zone (padding-top below the top bar); progress bar is indeterminate (40 % segment sliding, --ease-in-out, 1.6 s; static and centred under reduced motion), no aria-valuenow. Error card = US-004 card (opaque --color-surface, --radius-xl, --shadow-3, max 520 px, 48 px badge, h2 tabindex="-1", role="alert"). Buttons stacked, centred: primary "Try again", then (2nd failure onward, failed only) secondary .btn "Reload page" (reloads the document).
  • Skip links: two a elements first in the DOM, clipped until focused, then opaque --color-surface pill, --toggle-size high, 16/600, --shadow-3, at --float-inset from the top-left corner, standard focus ring. "Skip to alerts" opens the right panel (and closes the left drawer in drawer mode) before moving the focus.
  • Tooltips (panel buttons, view bar): 400 ms on hover, immediate on keyboard focus, Esc closes, aria-describedby. Panel buttons: bubble below, aligned to the screen edge (left panel: left edge, right panel: right edge).
  • Glass and fonts: every floating surface uses .glass (fallback opaque, never below 86 %). Inter is declared in tokens.css (local() first, then the self-hosted file); this page only uses local().
  • First paint: html background = --color-bg and color-scheme from the system before React loads (no white flash in dark); <noscript> text as shown above.
