Custom desk size

Onglet Desk de la barre latérale (base : US-006). Custom size est la 8e ligne du groupe radio « Desk model » ; la choisir déplie, dans la même carte, trois NumberField Width / Depth / Height en cm avec l'équivalent mm. Toutes les lignes passent aux nouvelles métriques (« cm » jamais seul à la ligne, §5). Le dessin de la scène est un substitut qui suit les cotes.

1. Fenêtre macOS 1366 px, clair (interactive)

Zone sous la barre d'outils : 1366 × 716. Flèches, stepper et molette (champ focalisé) appliquent à chaque pas : 1 cm, Maj 0,1, Ctrl 10 ; Début / Fin = bornes. Une saisie s'applique à Entrée ou à la sortie du champ ; hors bornes ou vide : erreur, la scène garde la dernière valeur valide ; Échap restaure. Choisir une autre ligne referme les champs, les valeurs sont gardées. Le volet est défilé : à l'ouverture, le bloc des champs est amené dans la vue (le focus reste sur la ligne).

Annonce aux lecteurs d'écran (masquée dans l'app), regroupée à 400 ms : Custom desk. 150 by 75 cm, height 74 cm.

2. Sombre 1366 px : saisie hors bornes, borne atteinte

Width contient « 45 » (validé par Entrée) : contour 2 px, icône, message relié ; le résumé et la scène montrent toujours 150 cm. Height est à 130 cm : le bouton + est désactivé (le texte des bornes reste sous la carte).

3. États de la ligne et des champs

De gauche à droite : Custom size jamais utilisée (Standard actif, plan en pointillé) ; bureau d'angle actif, ligne désactivée avec sa raison, aucun champ ; champs ouverts avec focus clavier sur Width, Depth vidé puis validé, Height à la borne haute. Sur fond de studio pour montrer le matériau.

4. Tiroir (iOS 390 × 844), clair et sombre

Superposition flottante (US-005 §15) : 326 px de large, colonne utile 302 px ; même composition empilée (libellé et mm, puis champ et stepper). Échap dans un champ avec brouillon ou erreur restaure la valeur et ne ferme pas le tiroir.

5. « cm » sur une ligne : avant / après

Colonne utile réelle : 248 − 2 × 12 − 1 = 223 px (et non 235). Avant : texte de 97 px, « cm » passait seul à la ligne (QA US-006). Après : padding 6 / 12 / 6 / 8, écart 8, coche 16 → texte de 115 px, et espaces insécables (U+00A0) après « × » et avant « cm » : la seule coupure possible reste après le premier nombre (« 239.9 » / « × 99.9 cm ») si la police ou le zoom l'imposent.

7. Consignes developer

  • Structure : la carte (--color-surface, --radius-lg, overflow: hidden) devient un wrapper qui contient le RadioGroup (simple grille, sans fond) puis, en frère, le bloc des champs. Les champs ne doivent pas être dans le radiogroup : le listener Début / Fin de DeskPanel et les flèches de React Aria captureraient leurs touches. Custom size = 8e Radio (value="custom", isDisabled si bureau d'angle ; Début / Fin et flèches la sautent alors).
  • « cm » sur une ligne (toutes les lignes, résumé, erreurs, mm) : espaces insécables dans les chaînes de src/locales/en/, écrits   pour rester visibles en revue, ex. "size": "{{width}} × {{depth}} cm", "{{value}} mm". Nouvelles métriques de .row : padding var(--row-pad-y) var(--space-3) var(--row-pad-y) var(--space-2), gap: var(--space-2), coche --icon-sm. Garder overflow-wrap: anywhere (jamais de rognage à 320 px).
  • Vignette : thumbScale() reçoit les modèles du catalogue et un spec fictif aux bornes max de Custom size (largeur 2400 mm) : toutes les vignettes rapetissent de 14 %, aucune ne déborde, l'échelle ne bouge pas pendant la saisie. Pointillé : stroke-dasharray: 3 2, fill-opacity: 0.
  • NumberField (wrapper ui/components/NumberField sur RAC) : valeur seule dans l'input (16 px : pas de zoom iOS), inputMode="decimal", nom accessible = libellé + suffixe (aria-labelledby « Width cm »), suffixe aria-hidden. Ne pas passer minValue / maxValue à RAC : il borne en silence à la sortie, alors que l'UX veut garder le texte et afficher l'erreur ; validation maison sur les bornes du catalogue, steppers désactivés par nous. Maj (0,1) et Ctrl (10) dans onKeyDown (RAC ne les gère pas). Steppers hors Tab (défaut RAC), nommés « Decrease width » / « Increase width ». Molette au focus seulement.
  • Échap : avec brouillon ou erreur, restaure et stopPropagation() (sinon le tiroir se ferme, §15) ; sans brouillon, laisser remonter. Entrée en erreur : focus gardé ; sortie par Tab : jamais de retour forcé.
  • Ouverture : grid-template-rows: 0fr → 1fr en --duration-base / --ease-standard + visibility (replié = hors Tab et hors arbre), instantané en reduced motion via les tokens. Le volet .pane désactive les transitions de son contenu (:where(.pane *)) : le bloc déclare la sienne. Après ouverture, amener le bloc dans la vue (scrollIntoView({ block: "nearest" }), sans smooth en reduced motion) : à 716 px de haut il est sous le pli. Focus laissé sur la ligne.
  • Textes : clés desk.custom.* de l'UX §5 ; l'équivalent mm suit le texte du champ pendant la frappe (rien n'est appliqué) et disparaît si le texte n'est pas un nombre. Proposition : tiret demi-cadratin (–) dans error.* et range (« 800–2400 mm »), à trancher par l'ux-designer.
  • Tokens : aucun nouveau, tokens.css inchangé. Icônes Lucide à ajouter au registre Icon : minus, plus, circle-alert (lucide-react déjà présent).
  • Contrastes : contour du champ 3,6:1 / 5,2:1 ; contour d'erreur et message 6,6:1 / 7,4:1 ; mm et raison text-muted 8,4:1 / 8,3:1 ; anneau 7,0:1 / 8,0:1 ; glyphes du stepper sur fill ≥ 14:1 ; dimensions actives 6,7:1 / 8,1:1.
