# UX — US-007 Taille de bureau personnalisée [UI]

Périmètre : "Custom size" dans l'onglet Desk (W3/W7). Dépend de US-006 (liste radio, résumé, annonce globale). Aucun nouvel écran. Bornes (décision 30) : rect 800-2400 × 500-1000 × 600-1300 mm, injectées depuis le catalogue ; angle sans "Custom size".

## 1. Parcours
Carol a un bureau de 150 × 75 cm, absent de la liste -> elle choisit la ligne **Custom size** (dernière de la liste) -> les champs s'ouvrent dessous, préremplis avec le bureau courant (aucun saut dans la scène) -> elle règle largeur, profondeur, hauteur -> le bureau suit dans la scène -> le résumé « Selected » et la ligne reprennent ses valeurs. Choisir une autre ligne referme les champs ; ses valeurs sont gardées pour son retour. Aucun bouton « Apply » (cohérent avec US-006 : tout s'applique directement, tout est réversible).

## 2. Wireframes (panneau 248 px, colonne utile 235 px)
```
 ...lignes de bureaux (US-006)...
 ┌──────────────────────────────────┐
 │ ┌─────┐ 150 × 75 cm          ✔   │  ligne radio "Custom size" ACTIVE
 │ │ ▭▭  │ Custom size              │  (cotes en cm = valeurs courantes ; vignette à l'échelle)
 │ └─────┘                          │
 │ Width                            │  libellé visible 14 px
 │ [ − ] [  150   cm ] [ + ]        │  NumberField, stepper 32 px mini
 │ 1500 mm                          │  équivalent mm, atténué, 1 ligne
 │ Depth        [ − ] [ 75 cm ] [ + ]│  (idem, empilés : un champ par ligne)
 │ Height       ...  = 740 mm       │
 │ ⚠ Enter a width between 80 and   │  erreur sous le champ, icône + texte
 │   240 cm (800-2400 mm).          │
 └──────────────────────────────────┘
 SELECTED  Custom, 150 × 75 cm / 1500 × 750 × 740 mm / Width × depth × height
```
Corner desk actif : la ligne Custom size reste visible mais **désactivée**, avec le texte « Rectangular desks only » (pas de ligne qui disparaît, pas de bouton mort silencieux). Valeur du champ : cm avec une décimale max (sans « .0 »).

## 3. Comportement
- **Appliqué en direct** : flèches du clavier, stepper, molette (sur focus) appliquent à chaque pas. **Saisie au clavier numérique** : appliquée à la validation (Entrée ou sortie du champ), car « 1 » en cours de frappe de « 150 » serait hors bornes. Valeur valide -> scène + résumé + alertes recalculées une fois.
- Pas : 1 cm (10 mm) ; Maj 0,1 cm (1 mm) ; Ctrl 10 cm (100 mm). Début/Fin = min/max. Bornes atteintes : stepper désactivé du côté atteint (jamais seul signal : le texte de la borne est dans l'aide).
- **Valeur hors bornes ou vide** : la scène garde la dernière valeur valide ; le champ garde le texte saisi, `aria-invalid="true"`, bordure erreur + icône + message (jamais la couleur seule), relié par `aria-describedby`. À **Entrée**, le focus reste dans le champ (le message est lu). À la sortie par Tab, le focus n'est **pas** ramené de force (piège clavier, WCAG 3.2.2) ; le champ reste en erreur et le résumé montre la valeur réellement appliquée. Écart avec le critère de la fiche (« le focus revient au champ ») : à valider par le scrum-master.
- Échap dans un champ : remet la dernière valeur valide.
- Ligne active = Custom size tant que l'on est en mode personnalisé, même si les valeurs égalent un modèle (sinon les champs disparaîtraient en pleine saisie). `deskSpec` compare largeur, profondeur et hauteur.
- Cadrage de vue, limites de zoom : comme US-006 §4.3 (recadrage 480 ms après la validation, pas à chaque pas d'une rafale ; instantané en reduced motion).

## 4. États
| État | Rendu |
|---|---|
| Replié (autre ligne active) | une ligne "Custom size" avec dernières cotes ou, jamais utilisée, `Set your own size` |
| Ouvert | champs sous la ligne, focus sur la ligne (pas sur le premier champ) ; Tab entre dans Width |
| Erreur | §3 ; plusieurs champs peuvent être en erreur, un message chacun |
| Chargement / scène en échec / WebGL absent | champs utilisables ; valeurs mémorisées, appliquées au démarrage de la 3D |
| Angle actif | ligne désactivée, `Rectangular desks only` |
| Succès | aucun toast : scène, résumé, annonce |

## 5. Annonces et textes (clés `desk.custom.*`)
| Clé | Texte |
|---|---|
| `title` / `hint` | `Custom size` / `Set your own size` |
| `width`, `depth`, `height` | `Width`, `Depth`, `Height` |
| `unit` / `mm` | `cm` / `{{value}} mm` |
| `error.width` | `Enter a width between {{min}} and {{max}} cm ({{minMm}}-{{maxMm}} mm).` |
| `error.depth`, `error.height` | idem avec `a depth`, `a height` |
| `error.empty` | `Enter a {{field}} in cm.` |
| `cornerDisabled` | `Rectangular desks only` |
| Résumé 1re ligne | `Custom, {{width}} × {{depth}} cm` |
| Annonce (regroupée 400 ms) | `Custom desk. {{width}} by {{depth}} cm, height {{height}} cm.` (+ ` {{count}} issues.` si alertes) |
| Annonce d'erreur (`role="alert"`) | le message d'erreur lui-même, une fois à l'apparition |

## 6. Clavier et lecteurs d'écran
Ligne Custom size = radio du groupe `Desk model` (flèches, Espace comme US-006). Tab : ligne -> Width -> Depth -> Height -> suite ; Maj+Tab inverse. Chaque NumberField : libellé visible lié, `aria-describedby` = équivalent mm + erreur éventuelle, steppers nommés `Decrease width` / `Increase width`, `inputmode="decimal"`. Focus 3 px visible partout, cibles >= 32 px, texte >= 14 px, `prefers-reduced-motion` : aucune animation d'ouverture (sinon 200 ms). Zoom 200 % et 320 px : pas de rognage.

## 7. Critères UX testables
1. Une ligne radio "Custom size" termine la liste ; la choisir ouvre Width, Depth, Height préremplis avec le bureau courant, sans changer la scène.
2. Chaque champ : libellé visible, unité "cm" et équivalent mm visibles ; "cm" reste sur une ligne dans 235 px à 1366 et 1024 px.
3. Flèches/stepper appliquent à chaque pas (1 cm ; Maj 0,1 ; Ctrl 10) ; la saisie s'applique à Entrée ou à la sortie du champ ; une seule recalcul d'alertes par validation.
4. Hors bornes ou vide : scène inchangée, message exact §5 relié par `aria-describedby`, `aria-invalid`, icône + texte + bordure ; focus conservé à Entrée, jamais forcé à la sortie par Tab.
5. Échap restaure la dernière valeur valide ; les bornes proviennent du catalogue (aucun nombre en dur).
6. La ligne Custom size active a contour 2 px, coche, fond `accent-subtle`, `aria-checked` ; elle reste active même si les valeurs égalent un modèle ; le résumé affiche cm, mm et hauteur.
7. Bureau d'angle actif : ligne désactivée avec `Rectangular desks only`, aucun champ.
8. Un 1400 × 700 de hauteur différente n'est pas « Standard » (résumé et ligne active corrects).
9. Annonce regroupée à 400 ms, une seule après une rafale de 5 pas ; erreur annoncée une fois.
10. Retour à un modèle : champs refermés, valeurs personnalisées gardées pour le retour ; focus resté sur la ligne.
11. Le bureau entier reste visible dans la zone libre (marge >= 24 px) à 1366×768 après validation.
12. Texte >= 14 px, cibles >= 32 px, contrastes AA clair et sombre, reduced motion respecté ; textes identiques à `src/locales/en/`.

## 8. UX-7 de US-005 reformulé (à reporter dans la fiche archivée)
> UX-7. Ouvrir ou replier un panneau ne déplace ni l'orientation ni la cible de la caméra ; le dock suit la zone libre entre les panneaux et n'est jamais recouvert par un volet ouvert.

## 9. Note pour l'ui-designer
Le « cm » des dimensions (lignes, champs, résumé) ne doit jamais passer à la ligne dans la colonne de 235 px (écart de la QA de US-006) : espace insécable avant l'unité, `white-space: nowrap`, champ à largeur fixe ~96 px avec stepper compact ; vérifier à 1366 et 1024 px. L'erreur doit combiner icône, texte et bordure.
