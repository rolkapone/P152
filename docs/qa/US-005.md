## Requalification (developer, correction cycle 1/3, 2026-10-31)
Corrections : 2 workers en local comme en CI (`playwright.config.ts`, SwiftShader sature le CPU) ; plus aucun `waitForTimeout` dans `tests/e2e` (`scene.spec.ts` vérifie le rendu à la demande sur une durée exacte d'horloge factice : `page.clock` figée après le chargement puis `runFor`) ; règle de lint sur `tests/e2e` qui refuse `waitForTimeout` (`pnpm check` échoue s'il revient, testée dans `lint-rules.test.ts`).
Séquence : `pnpm check` vert (591 tests, 2 passages) → `pnpm build:e2e` → `pnpm test:e2e --repeat-each=5`, configuration par défaut (2 workers, sans preview lancée à part) : **460/460, 0 échec, 0 instable, 19,7 min**. `scene.spec.ts --repeat-each=5` isolé : 40/40.
Restent : l'avertissement `THREE.Clock: This module has been deprecated` vient de `@react-three/fiber` 9.8.2 (dernière version, qui crée encore un `THREE.Clock` avec three r186) ; non corrigeable sans attendre une version de R3F. `--repeat-each=10` complet non relancé (environ 40 min).
